# 🧠 Responsible AI Checklist

## ✅ Fairness
- Dataset balanced across classes
- SHAP used for feature transparency

## ✅ Privacy
- No personal identifiable info (PII)
- Model does not store user inputs

## ✅ Consent
- Data sourced ethically
- Usage explained in README

## ✅ Transparency
- SHAP plots in dashboard
- Metrics displayed clearly

## ✅ Accountability
- CI/CD pipeline in place
- Versioned code and model
